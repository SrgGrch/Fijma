# Локальные стили и переменные

Обработчики работают с локальными стилями, коллекциями и переменными открытого документа. Внешние ресурсы и расширенные коллекции не изменяются. Основные операции проверены в Desktop; на проверенной лицензии второй режим был недоступен. Возможности других тарифов и ОС этим прогоном не подтверждены.

Для изменения существующего ресурса `expected` относится к нему; для применения стиля, привязки переменной и режима узла — к узлу. `expected.related` позволяет дополнительно проверить другие узлы, стили, коллекции и переменные по их ID. Сравниваются запрошенные фактические поля после загрузки шрифтов и зависимостей. Для стилей значения проверяются через соответствующие поля `paints`, `effects`, `layoutGrids` или поля типографики, для переменных — через `valuesByMode`, для коллекций — через `modes` и `variableIds`. Состояние проверенных связей дополнительно контролируется непосредственно перед записью.

| Действие | Основной объект `expected` | Что полезно проверить дополнительно |
| --- | --- | --- |
| `createStyle`, `createCollection` | Новый объект ещё отсутствует | При необходимости связанные объекты через `related` |
| `updateStyle`, `deleteStyle` | Стиль: `name`, `type` и меняемые поля значения | Связанные узлы через `related` |
| `applyStyle`, `unbindStyle` | Узел: `name`, соответствующий style ID, `boundVariables` | Применяемый стиль через `related`; для узла доступны `parentId` и `children` |
| `updateCollection`, `deleteCollection`, `createMode`, `renameMode`, `deleteMode`, `createVariable` | Коллекция: `name`, `modes`, `variableIds` | Затрагиваемые переменные через `related` |
| `updateVariable`, `deleteVariable`, `setVariableValue`, `setVariableAlias` | Переменная: `name`, `type`, `valuesByMode`, при изменении — `description`, `hiddenFromPublishing` | Коллекция и целевая переменная alias через `related` |
| `bindVariable`, `unbindVariable`, `setNodeMode` | Узел: `name`, `boundVariables`, `explicitVariableModes`, при необходимости `parentId` и `children` | Переменная и коллекция через `related` |

Для grid-связи можно прочитать `gridStyleId` и `layoutGrids` через `figma_get_nodes` и передать их в `expected`. `related` не является автоматической проверкой всех потребителей: клиент явно выбирает значимые связи.

Для операций с узлами основной `expected` относится к целевому узлу: для переименования и обновления — например `name` и меняемые свойства, для текста — `characters`, `textSegments` и стилевые связи, для геометрии и Auto Layout — геометрия, `layout`, `constraints` и размеры, для перемещения и группировки — `parentId` и порядок `children` соответствующих родителей в `related`. При создании узла основным объектом проверки служит родитель, при булевой операции и группировке — первый исходный узел; остальные узлы, родители и общие ресурсы можно указать в `related`. `expected` для создания страницы может содержать только `related`. Значимые сведения о стиле или переменной сравниваются теми же полями, что и при работе непосредственно с ресурсом.

Стиль применяется и снимается штатными методами Figma; изменение общего стиля сохраняет ссылки его потребителей. Явная операция снятия связи передаёт пустой style ID. Применение и изменение не снимают привязки переменных молча: при конфликтующей привязке операция отклоняется. Текстовые операции загружают необходимые шрифты. Некоторые поля типографики из общего контракта не поддерживаются TextStyle и отклоняются до выполнения пакета.

Каждая переменная имеет тип и значения по mode ID. Alias проверяется на тип и циклы по всем достижимым режимам, включая вложенные цветовые aliases; размер обхода ограничен. Проверка намеренно консервативна: цикл, достижимый при разных режимах одной коллекции, также отклоняется. Явная операция `setVariableValue` может заменить alias значением, а `unbindVariable` снимает только указанную связь. Добавление режима может быть недоступно на текущем тарифе и возвращает `CAPABILITY_UNAVAILABLE` без обхода ограничения.

Удаление стиля или переменной и удаление режима или коллекции может изменить связи потребителей. Результат сообщает известные изменённые ID и предупреждение о побочных эффектах, но не перечисляет потребителей поиском по всему документу. Удаление коллекции дополнительно сообщает ID её переменных; изменение состава режимов сообщает ID её переменных для повторного чтения.
