## Реализация и автоматические проверки

На момент предыдущей остановки три сабагента GPT-6.1 Terra medium написали обработчики и тесты, основной агент проверил интеграцию. В диспетчер подключены все 51 имя операции из схемы; ограничения значений и возможностей редактора сохраняются. Полный `npm test` на тогдашней версии прошёл, включая сквозные проверки SDK → сервер → UI → candidate с имитацией Figma. `openspec validate figma-mcp-bridge-mvp --strict --json` и `git diff --check` также прошли для той версии. Чистая установка зависимостей и отдельный TypeScript typecheck в этом проходе не выполнялись.

На тот момент закрыты 3.3, 5.2 и 6.4: прогресс составлял 30/45. Ниже реализации, вошедшие в тогдашнюю сборку; последующая Desktop-проверка выявила дополнительные исправления, описанные ниже:

- [Оформление и графика](graphics.md): частичные fills/gradients/strokes/opacity/corners/effects, явный locked, поддержка оформления при createNode/updateNode для обычных узлов и текста. Незатронутые стили и переменные, включая привязки в gradientStops, сохраняются. Импорт ограниченных PNG/JPEG/SVG и четыре булевых операции подключены к candidate; WebP возвращает CAPABILITY_UNAVAILABLE. Лимиты берутся из согласованного контекста. Native-проверку корректного/повреждённого изображения, SVG и геометрии boolean ещё предстоит выполнить: 6.5 и 6.6 оставлены открытыми.
- [Компоненты и экземпляры](components.md): создание/преобразование, наборы вариантов, определения, instances, overrides, swapVariant и явный detach. updateNode допускает конечные свойства COMPONENT/INSTANCE; createNode не обходит предметные операции. Клонирование и удаление поддерживают созданные производные типы. Нативное наследование и overrides новых обработчиков в Desktop ещё не проверены: 8.1/8.2 остаются открытыми.
- [Локальные ресурсы](resources-write.md): CRUD paint/text/effect/grid стилей, коллекций, переменных и modes, aliases, bind/unbind и режимы узлов. Ресурсы внешних библиотек отклоняются. Типы, локальность, связанные ресурсы, циклы всех достижимых modes и ограничения обхода проверяются до записи; известные побочные эффекты возвращаются явно. Запись ресурсов проходит автоматический сквозной маршрут, но новая реализация ещё не принята в Desktop: 8.3–8.5 открыты.
- Общий механизм expected поддерживает узлы и ресурсы в одной related-проекции. Тесты ручных изменений во время загрузки шрифтов, чтения зависимостей и обхода aliases подтверждают CONFLICT до мутации. Привязки повторно проверяются непосредственно перед записью. Набор предусловий описан в справочниках операций.
- Readback новых операций проверяет фактические свойства, style IDs, aliases/modes, component links/overrides и известные удалённые группы. Ошибка проверки не объявляется подтверждённым успехом.
- Stop прерывает подготовку компонентов после ближайшей ограниченной порции работы. Тесты подтверждают прекращение дальнейших чтений, сохранение уже применённых шагов и отсутствие автоматического Undo.
- UI при visibilitychange с document.hidden и pagehide разрывает соединение, а connect скрытого документа не выполняется. Автотесты проверяют эти события; поступление событий при настоящем переключении File A → File B ещё не проверено, поэтому 1.2/3.2 остаются открытыми.
