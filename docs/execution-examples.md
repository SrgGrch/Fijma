# Trusted execution examples

Both files are async function bodies for `figma_execute` (`language: "javascript"`), with `args` a JSON object. Typography defaults to the current page and can be narrowed with `sectionId`; for cards, select a section or supply `sectionId`. They await all work, leave no background listeners and yield at least every 50 nodes and typography segments. These examples execute with document write access; do not treat selection as a security boundary. For another page explicitly load it first with `page.loadAsync()`.

`typography-statistics.js` loads the current page with `loadAsync()`, then reads styled segments and counts characters per font name, size and full `lineHeight` value, including PIXELS, PERCENT and AUTO. It reports at most 100 combinations, not individual nodes. It does not edit text; editing text requires loading every affected font using `figma.loadFontAsync` first. Mixed node-level properties are never used as scalar values.

`cards.js` visits instance roots in the section, reports existing direct overrides, and accepts optional `properties` (component property names and values), `layout` (spacing/padding on auto-layout instances), `bindings` (opacity or spacing/padding to FLOAT variable IDs), and `nestedLayout` (an object `{ selector, layout }`; selector is a descendant ID or name, and layout uses the same spacing/padding fields). Every matching descendant is attempted; unsupported nodes or rejected writes are skipped. Unsupported properties, incompatible variables and requests for `structuralChange` are reported as skipped. It never detaches instances or changes their structure; nested layout only writes supported properties when Figma permits it. Figma may reject individual overrides or bindings; failures are recorded, prior changes are not rolled back. The report includes at most 20 cards, five override entries per card and five fields per override, and marks truncated arrays; it includes at most 100 skipped entries plus their total count.

The examples are fixtures for development; their behavior in Figma Desktop has not been verified in this change.
