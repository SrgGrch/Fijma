# Доверенное выполнение

`figma_execute` — дополнительный инструмент, не fallback для ошибок `figma_apply_batch`. Сначала получите `figma_get_context` и используйте возвращённый scope. Пользователь отдельно включает доверенный код в UI плагина; batch-разрешение не включает скрипты. Адресат — привязанный файл, даже если видима другая вкладка.

Вход: `scope`, UUIDv7 `operationId`, `language` (`javascript` или `typescript`), `code`, необязательные JSON `args`. Code — тело async-функции, например `return { page: figma.currentPage.name };`. Доступны настоящий `figma`, `args`, `console.log/info/warn/error/debug`, `execution.checkCancelled()` и `await execution.yield()`. TypeScript преобразуется esbuild без проверки типов. Imports не поддерживаются. Код не исполняется сервером.

Все операции изменения проходят одну очередь. Повтор того же ID возвращает известное состояние, другой payload с тем же ID отклоняется. Результат содержит `kind: execute`, статус, `effects`, `logs`, `logsTruncated`, `warnings` и `value` либо `resource`. JSON DTO не должен включать Figma nodes, циклы, функции, BigInt или getters. Верните обычные объекты с нужными полями.

`effects: none` допустим только до запуска, после запуска — `unknown`. Это не read-only или транзакция. Ошибка/отмена могут наступить после записи. `succeeded` относится к завершению возвращённого Promise и подготовке результата, а не к проверке всех изменений. Undo автоматически не выполняется.

Исходник ограничен 32 KiB UTF-8, args — 8 KiB, весь wire command — 64 KiB, inline envelope — 32 KiB, результат — 256 KiB. Логи: 8 KiB/100 записей; DTO: глубина 32 и 10000 значений. Большой результат передаётся чанками и публикуется как application/json resource с TTL 60 секунд; хранилище не более 16 записей/4 MiB. При смене владельца/сессии доступ к ресурсам прекращается. Повтор status может опубликовать новый ресурс, учитывайте его TTL и лимиты.

При `OUTCOME_UNKNOWN` запрашивайте `figma_get_operation` с прежним ID. Не повторяйте скрипт с новым ID, пока не проверили документ. Отмена и Stop кооперативны: используйте yield в обходах, await всей работы, не оставляйте callbacks, listeners или detached promises и не изменяйте bridge/UI. Эти правила — договор доверенного кода, не sandbox. Синхронный бесконечный цикл может потребовать ручного закрытия плагина/редактора.

При обрыве во время скрипта передача документа блокируется до новой plugin-сессии. Разрешения сбрасываются. Перезапустите плагин, перечитайте контекст и проверьте файл. Серверная диагностика по умолчанию не сохраняет исходники/args/результаты/пользовательские логи; сам результат скрипта может содержать данные документа.

[Каталог API](execution-catalog.md) и [примеры](execution-examples.md) помогают готовить скрипты. [Desktop-протокол](execution-probe.md) проверяет фактическую совместимость — наличие типизации не является таким доказательством.
