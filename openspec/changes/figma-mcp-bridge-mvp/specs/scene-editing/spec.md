# Редактирование структуры и оформления

## Purpose

Позволить создавать и изменять настоящие редактируемые узлы Figma в текущем документе через проверяемые декларативные операции.

## ADDED Requirements

### Requirement: Создание и жизненный цикл объектов
Система MUST поддерживать создание, переименование, клонирование и удаление страниц и поддерживаемых узлов. Базовые типы MUST включать frame, rectangle, ellipse, line, polygon, star и text; группы и производные типы MUST создаваться соответствующими предметными операциями.

#### Scenario: Новый экран
- **WHEN** агент создаёт фрейм, фигуру и текст пакетом
- **THEN** появляются отдельные редактируемые узлы с фактическими nodeId и родительскими связями

#### Scenario: Клонирование и удаление
- **WHEN** агент клонирует узел, переименовывает копию и удаляет исходный узел с актуальными предусловиями
- **THEN** возвращаются ID копии и удалённого узла; исходное поддерево недоступно при повторном чтении

#### Scenario: Удаление последней страницы
- **WHEN** операция нарушает ограничение Figma на структуру документа
- **THEN** возвращается ограничение API без скрытого создания запасной страницы

### Requirement: Родители и порядок слоёв
Система MUST поддерживать перемещение, изменение родителя, порядка детей, группировку и разгруппировку. Циклы, недопустимые родители, межсессионные ссылки и неподдерживаемые изменения структуры экземпляра MUST отклоняться без автоматического отделения.

#### Scenario: Перемещение между страницами
- **WHEN** узел перемещается в допустимый контейнер другой страницы текущего файла
- **THEN** новая родительская связь, индекс и фактическая геометрия возвращаются после записи

#### Scenario: Узел внутри собственного потомка
- **WHEN** агент пытается поместить контейнер в его потомка
- **THEN** возвращается INVALID_ARGUMENT без перемещения

#### Scenario: Редактирование структуры экземпляра
- **WHEN** запрос требует недопустимого добавления ребёнка внутрь instance
- **THEN** возвращается ошибка ограничения без detachInstance

### Requirement: Геометрия и компоновка
Система MUST поддерживать позицию, размеры, поворот, constraints и Auto Layout: направление, отступы, gap, выравнивание, wrap и режимы размеров поддерживаемых узлов. Координаты MUST иметь явную систему отсчёта; недопустимые сочетания MUST отклоняться.

#### Scenario: Изменение Auto Layout
- **WHEN** агент задаёт фрейму направление, отступы и промежутки, а детям допустимые режимы размеров
- **THEN** повторное чтение показывает применённые свойства и вычисленные Figma границы детей

#### Scenario: Недопустимый размер
- **WHEN** переданы нечисловые, бесконечные или запрещённые для типа размеры
- **THEN** шаг отклоняется до записи без молчаливого исправления значения

### Requirement: Визуальные свойства
Система MUST поддерживать заливки, градиенты, обводки, прозрачность, скругления и эффекты в разрешённых для типа сочетаниях. Частичный update MUST сохранять незаданные свойства; замена коллекции свойств MUST быть явной.

#### Scenario: Изменение только заливки
- **WHEN** агент меняет fills существующего узла
- **THEN** strokes, effects и геометрия сохраняются, если их изменение не запрошено

#### Scenario: Заблокированный слой
- **WHEN** запись требует скрытого снятия блокировки или обхода ограничения Figma
- **THEN** операция сообщает ограничение; снятие блокировки возможно только как явное поддерживаемое изменение свойства

### Requirement: Изображения и SVG
Система MUST принимать ограниченные по объёму данные изображения или SVG, создавать поддерживаемые ресурсы и возвращать их ID. Произвольная загрузка внешнего URL и чтение пути файловой системы по команде агента MUST NOT быть частью MVP.

#### Scenario: Добавление изображения
- **WHEN** агент передаёт допустимые байты изображения и параметры размещения
- **THEN** Figma содержит image fill на редактируемом узле, а ответ содержит фактические идентификаторы ресурса и узла

#### Scenario: Небезопасный или неверный SVG
- **WHEN** SVG содержит запрещённую внешнюю ссылку, скрипт, недопустимый формат либо превышает лимит
- **THEN** импорт отклоняется без внешнего сетевого запроса и без исполнения содержимого

### Requirement: Базовые булевы операции
Система MUST поддерживать union, subtract, intersect и exclude допустимых узлов через Plugin API. Редактирование vectorNetwork, контрольных точек и сложных кривых MUST NOT предоставляться.

#### Scenario: Объединение фигур
- **WHEN** агент применяет поддерживаемую булеву операцию к допустимым фигурам
- **THEN** возвращаются nodeId результата, его родитель и затронутые исходные узлы с фактическими последствиями операции

#### Scenario: Запрос сложного вектора
- **WHEN** агент запрашивает изменение контрольных точек кривой
- **THEN** возвращается CAPABILITY_UNAVAILABLE без обхода через произвольный код
