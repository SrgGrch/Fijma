# Локальная дизайн-система

## Purpose

Позволить агенту работать с компонентами, стилями и переменными открытого файла, сохраняя связи и явно сообщая ограничения редактора.

## ADDED Requirements

### Requirement: Только ресурсы текущего файла
Система MUST предоставлять чтение и поддерживаемые изменения локальных компонентов, наборов вариантов, стилей, коллекций и переменных. Импорт и изменение ресурсов внешних библиотек MUST NOT выполняться; уже существующие внешние связи MUST быть различимы при чтении.

#### Scenario: Недоступный библиотечный ресурс
- **WHEN** агент запрашивает импорт компонента или стиля из внешней библиотеки
- **THEN** возвращается CAPABILITY_UNAVAILABLE без копирования внешнего ресурса под видом локального

### Requirement: Главные компоненты и варианты
Система MUST создавать локальные компоненты, преобразовывать допустимые узлы в компоненты, создавать component set, задавать свойства компонентов и варианты. При изменении главного компонента MUST возвращаться известные широкие побочные эффекты без approval-шагов.

#### Scenario: Создание вариантов
- **WHEN** агент объединяет допустимые локальные компоненты в набор вариантов и задаёт им значения свойств
- **THEN** Figma содержит component set со связанными вариантами, а ответ возвращает его ID и схему свойств

#### Scenario: Изменение главного компонента
- **WHEN** агент меняет главный компонент с существующими экземплярами
- **THEN** обновление исполняется без подтверждения, результат описывает известную область влияния без заявления о полном подсчёте, если его нет

### Requirement: Экземпляры с сохранением связей
Система MUST создавать instance локального компонента, менять поддерживаемые свойства экземпляра и переключать варианты через поддерживаемое API. Отделение MUST выполняться только отдельной явной операцией detachInstance.

#### Scenario: Переключение варианта
- **WHEN** агент меняет вариант экземпляра на допустимый вариант того же набора
- **THEN** экземпляр остаётся связанным с компонентом; возвращаются фактические свойства и сохранённые либо изменившиеся overrides

#### Scenario: Явное отделение
- **WHEN** агент явно вызывает detachInstance с актуальными предусловиями
- **THEN** связь с компонентом удаляется без подтверждения, а ответ содержит фактический результирующий nodeId и сведения о потере связи

### Requirement: Локальные стили
Система MUST читать, создавать, обновлять, применять, явно снимать и удалять локальные paint, text, effect и grid стили в поддерживаемых контекстах. Неподдерживаемое применение MUST давать ошибку без подмены стилевых связей значениями.

#### Scenario: Общий локальный стиль
- **WHEN** агент создаёт paint style, применяет его к двум узлам и меняет стиль
- **THEN** узлы сохраняют ссылку на стиль и отражают поддерживаемое Figma изменение

#### Scenario: Удаление используемого стиля
- **WHEN** агент явно удаляет используемый локальный стиль
- **THEN** операция исполняется без подтверждения в рамках Plugin API и сообщает фактические известные последствия для связей

### Requirement: Коллекции и режимы переменных
Система MUST читать, создавать, переименовывать и удалять локальные коллекции и переменные, управлять поддерживаемыми режимами и значениями по режимам. Типы и действующие ограничения лицензии/API MUST проверяться во время выполнения.

#### Scenario: Значения для двух режимов
- **WHEN** редактор поддерживает два режима и агент задаёт значения одной переменной в обоих
- **THEN** чтение возвращает коллекцию, modeId и типизированные значения, а доступные узлы могут использовать эти режимы

#### Scenario: Ограничение лицензии
- **WHEN** создание режима превышает доступные возможности редактора
- **THEN** возвращается CAPABILITY_UNAVAILABLE с причиной без создания заменяющей коллекции или константы

### Requirement: Aliases и привязки
Система MUST поддерживать совместимые aliases, привязку переменных к разрешённым свойствам и явное снятие привязок. Несовместимые типы и циклы MUST отклоняться; обычное редактирование MUST NOT молча заменять привязку константой.

#### Scenario: Alias локальной переменной
- **WHEN** агент создаёт совместимый alias и привязывает переменную к поддерживаемому свойству
- **THEN** повторное чтение показывает alias, modeId и привязку, а не только вычисленное значение

#### Scenario: Циклический alias
- **WHEN** новый alias создаёт цикл или ссылается на несовместимый тип
- **THEN** шаг отклоняется без сохранения недопустимой связи

#### Scenario: Запись константы в привязанное свойство
- **WHEN** агент обновляет свойство с переменной без явного запроса снятия привязки
- **THEN** сохраняется связь, если изменение совместимо, иначе возвращается конфликт без тихой подмены токена
