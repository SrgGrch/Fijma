# Структурированные инструменты и протокол

## Purpose

Предоставить агенту однозначные схемы чтения и изменения документа, согласованный протокол моста и результаты, позволяющие безопасно продолжать работу после ошибки.

## ADDED Requirements

### Requirement: Предметный каталог инструментов
Сервер MUST публиковать инструменты контекста, дерева, поиска, свойств, навигации, пакетной записи, статуса операций и экспорта с явными inputSchema. Фактические возможности, типы узлов и лимиты MUST быть доступны через контекст.

#### Scenario: Получение каталога без плагина
- **WHEN** MCP-клиент запрашивает список инструментов до подключения Figma
- **THEN** он получает схемы; контекст сообщает disconnected, а запрос документа возвращает NOT_CONNECTED

#### Scenario: Ограниченная возможность
- **WHEN** подключённый редактор не предоставляет запрошенную операцию
- **THEN** контекст отражает ограничение, а вызов возвращает CAPABILITY_UNAVAILABLE с причиной

### Requirement: Запрет произвольного кода
Система MUST принимать только перечисленные декларативные операции и разрешённые для типа поля. Произвольный JavaScript, eval, команды оболочки и универсальное присваивание произвольного пути MUST NOT быть доступны ни отдельным инструментом, ни запасным обработчиком.

#### Scenario: Обход через неизвестную операцию
- **WHEN** агент передаёт execute_js, неизвестное поле или вложенный код вместо параметров
- **THEN** схема отклоняет запрос до изменений документа

#### Scenario: Инструкции в тексте макета
- **WHEN** название слоя или текст содержит указания изменить адрес моста либо открыть другой файл
- **THEN** содержимое возвращается как данные и не влияет на полномочия или конфигурацию

### Requirement: Согласование внутреннего протокола
Мост MUST согласовывать версию собственного протокола, возможности, лимиты и сессию независимо от версии MCP. Несовместимость MUST блокировать исполнение; UI и выполняющая часть MUST проверять входящие сообщения на своих границах.

#### Scenario: Несовместимые версии
- **WHEN** версия плагина несовместима с версией моста
- **THEN** команды блокируются с PROTOCOL_MISMATCH и пояснением требуемой совместимости

#### Scenario: Повреждённое сообщение UI
- **WHEN** выполняющая часть получает сообщение с неверной схемой или сессией
- **THEN** сообщение отклоняется без обращения к изменяющим операциям Plugin API

### Requirement: Коррелируемый результат
Запрос MUST содержать operationId, сессию, поколение, тип команды, параметры и при необходимости исходное состояние. Ответ MUST содержать те же идентификаторы, статус, результаты шагов, затронутые nodeId, предупреждения и структурированную ошибку при сбое. ACK MUST NOT означать успех.

#### Scenario: Подтверждена только доставка
- **WHEN** мост получил ACK, но ещё не получил результат плагина
- **THEN** операция остаётся queued или running и не возвращается как succeeded

#### Scenario: Ошибка выполнения
- **WHEN** обработчик не смог выполнить команду
- **THEN** агент получает code, message, failedStep при наличии и recoveryAction без автоматического расширения области доступа

### Requirement: Согласованные состояния и ошибки
Система MUST различать queued, running, succeeded, failed, partially_applied, cancelled и unknown. Ошибки MUST различать отсутствие связи, старую сессию, чужой документ, аргументы, узел, возможность, шрифт, конфликт, лимит и неопределённый исход.

#### Scenario: Ошибка до и после изменений
- **WHEN** одна команда отклонена до записи, а другая оборвалась после подтверждённого первого шага
- **THEN** первая имеет failed без изменений, вторая partially_applied с известными изменениями; потерянное подтверждение может давать unknown

### Requirement: Совместимые ответы MCP
Сервер MUST возвращать результаты по согласованной версии MCP, соблюдать опубликованную outputSchema и выдавать ошибки выполнения инструментов с isError. stdout MUST содержать только сообщения MCP; диагностические сообщения MUST идти отдельно.

#### Scenario: Ошибка документа доступна агенту
- **WHEN** Figma возвращает ошибку шрифта
- **THEN** MCP-результат имеет isError и структурированную ошибку FONT_UNAVAILABLE; соединение MCP остаётся пригодным для следующего вызова

#### Scenario: Диагностика при stdio
- **WHEN** мост пишет диагностическое сообщение
- **THEN** оно не загрязняет stdout и не нарушает разбор MCP клиентом
