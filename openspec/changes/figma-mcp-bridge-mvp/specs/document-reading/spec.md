# Чтение документа и навигация

## Purpose

Дать агенту достаточный контекст живого документа для адресных изменений с управляемым объёмом чтения, поиска и передачи данных.

## ADDED Requirements

### Requirement: Обзор активного документа
Контекст MUST возвращать состояние моста, sessionId, поколение, доступные сведения файла, список страниц, текущую страницу, выделенные nodeId, режим записи, возможности и действующие лимиты. Обзор MUST NOT сериализовать содержимое всех страниц.

#### Scenario: Пустой файл
- **WHEN** агент получает контекст файла без пользовательских узлов
- **THEN** возвращаются существующие страницы и пустое выделение без ошибки и без создания объектов

### Requirement: Ограниченное дерево
Запрос дерева MUST задавать корневой узел/страницу и ограничения глубины, количества узлов и размера ответа. Результат MUST сохранять порядок детей, типы, nodeId и признак усечения; продолжение MUST быть явным.

#### Scenario: Поддерево превышает лимит
- **WHEN** запрошенное поддерево не помещается в согласованные лимиты
- **THEN** возвращается ограниченная часть, truncated и продолжение, а результат не выдаётся за полное дерево

#### Scenario: Другая страница
- **WHEN** агент читает поддерево не загруженной страницы текущего файла
- **THEN** загружается необходимая страница без обязательной загрузки остальных страниц и без изменения выделения

### Requirement: Поиск с явной областью
Поиск MUST поддерживать область текущего документа, страницы или поддерева, фильтры по имени и типу и ограниченный результат с продолжением. Полный поиск MUST обходить документ постепенно и сообщать неполноту.

#### Scenario: Продолжение поиска
- **WHEN** найдено больше узлов, чем допускает лимит страницы результатов
- **THEN** возвращаются nodeId, страница и ограниченные сведения, а cursor позволяет продолжить тот же запрос в той же сессии

#### Scenario: Устаревший cursor
- **WHEN** cursor использован с другой сессией, другим запросом или изменённой областью обхода
- **THEN** возвращается INVALID_CURSOR с требованием повторить поиск; система не заявляет полноту непроверенного результата

### Requirement: Явные свойства узла
Чтение узлов MUST возвращать запрошенную разрешённую проекцию фактических свойств, родителя, геометрию, видимость, блокировку и доступные связи. Смешанные и неподдерживаемые значения MUST отличаться от обычных значений и отсутствующего узла.

#### Scenario: Смешанное форматирование
- **WHEN** запрошены текстовые свойства узла с несколькими шрифтами
- **THEN** возвращаются признак mixed и сведения диапазонов по запросу без подстановки единственного шрифта

#### Scenario: Удалённый узел
- **WHEN** ранее прочитанный nodeId уже удалён вручную
- **THEN** запрос сообщает NODE_NOT_FOUND для этого узла и не подбирает замену по имени

#### Scenario: Скрытые и заблокированные узлы
- **WHEN** агент читает скрытые или заблокированные слои в своей области
- **THEN** они доступны для чтения с соответствующими флагами без скрытого снятия блокировки

### Requirement: Явная навигация
Отдельная команда MUST позволять выбрать существующие узлы и показать их в viewport текущего документа с загрузкой нужной страницы. Обычное чтение MUST NOT менять страницу, выделение или viewport без запроса навигации.

#### Scenario: Переход к узлу другой страницы
- **WHEN** агент явно просит показать существующий узел другой страницы
- **THEN** редактор открывает нужную страницу, показывает узел и возвращает фактическое выделение

### Requirement: Актуальность чтения
Кэш MUST быть ограничен сессией и инвалидироваться при наблюдаемых изменениях. Ответ MUST NOT представлять набор чтений как атомарный снимок документа; запись MUST проверять значимые свойства заново.

#### Scenario: Ручная правка после чтения
- **WHEN** пользователь изменил свойство после выдачи контекста
- **THEN** последующая проверка перед записью использует живое значение, а не доверяет сохранённому кэшу
