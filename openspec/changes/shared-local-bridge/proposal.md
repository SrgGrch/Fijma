# Proposal

## Why

Каждый запуск Codex создаёт отдельный stdio-сервер, который пытается занять один и тот же порт 55263. Пока предыдущий процесс жив, новый MCP-сервер переходит в failed. Нужен один общий мост, доступный независимым stdio-подключениям.

## What Changes

- Существующая команда `node dist/server/index.js` становится stdio-адаптером: подключается к общему мосту и автоматически запускает его при отсутствии.
- Общий процесс независимо от Codex владеет WebSocket-портом Figma и сохранённым сопряжением; закрытие адаптера не останавливает общий процесс.
- Каждый адаптер получает отдельную MCP-сессию. Инициализация и обнаружение инструментов доступны всем; доступ к документу имеет один клиент, остальные получают SESSION_BUSY без вытеснения владельца.
- Отключение владельца аннулирует его привязку к плагину до передачи управления; очередь и разрешение записи не наследуются.
- Добавляются защищённое локальное межпроцессное соединение, ограниченное ожидание запуска, явная остановка общего моста и инструкция перехода со старого сервера.
- Изолированный режим `FIGMA_MCP_PORT=0` сохраняется для существующих тестов и probes.

## Capabilities

### New Capabilities

- `shared-bridge`: жизненный цикл единого локального моста, подключения stdio-адаптеров и исключительное владение документом.

### Modified Capabilities

Нет опубликованных main specs. Изменение уточняет границу одного MCP-клиента из `figma-mcp-bridge-mvp/specs/bridge-session`: несколько транспортных подключений допустимы, но только один клиент имеет доступ к документу. Ограничения одного плагина и одного документа сохраняются.

## Impact

- `server/index.ts`: выбор режима адаптера, общего процесса, остановки и изолированного запуска.
- Общая инициализация из `server/index.ts`, `server/pairing-listener.ts`, `server/catalog.ts`, `server/pairing-file.ts`: переиспользование runtime, контроль владельца и сброс привязки.
- Новые модули локального IPC и запуска процесса; без новых зависимостей и изменений Plugin API/manifest.
- Процессные интеграционные тесты, существующие проверки MCP/плагина, `package.json`, `README.md`, `docs/launch.md` и ручной клиент.
- Переход требует однократно остановить старый несовместимый сервер; произвольный процесс на занятом порту автоматически не завершается. Конфигурация Codex сохраняет текущий путь команды.
