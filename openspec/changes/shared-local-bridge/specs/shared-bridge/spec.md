# Общий локальный мост

## Purpose

Позволить независимым запускам Codex использовать один локальный мост Figma без конфликта порта, сохраняя исключительное управление одним документом и границы сессий.

## ADDED Requirements

### Requirement: Прозрачный stdio-адаптер

Команда `node dist/server/index.js` MUST сохранять MCP stdio-интерфейс и подключаться к единому мосту для выбранных локальных настроек. stdout MUST содержать только MCP-сообщения; диагностика MUST идти в stderr без секрета сопряжения.

#### Scenario: Повторное открытие Codex
- **WHEN** новый клиент запускает адаптер при уже работающем совместимом мосте
- **THEN** адаптер использует существующий мост, проходит MCP-инициализацию и не пытается повторно занять WebSocket-порт Figma

### Requirement: Автоматический запуск единого моста

При отсутствии моста адаптер MUST автоматически запустить отдельный фоновый процесс без видимого окна. Параллельные запуски MUST сходиться к одному владельцу порта; ожидание подключения MUST иметь конечный срок. Адаптер MUST NOT завершать посторонний или работающий старый сервер ради освобождения порта.

#### Scenario: Одновременный первый запуск
- **WHEN** два адаптера стартуют без существующего моста
- **THEN** оба подключаются к одному готовому мосту, а лишние стартовые процессы завершаются без влияния на него

#### Scenario: Порт занят несовместимым процессом
- **WHEN** порт Figma занят старым сервером или посторонней программой без доступного совместимого моста
- **THEN** адаптер завершает попытку в ограниченный срок с понятной диагностикой конфликта, не завершая владельца порта

### Requirement: Защищённый локальный канал

Связь адаптера с мостом MUST быть локальной и взаимно аутентифицированной до допуска к MCP и управлению процессом. Секрет MUST NOT передаваться неаутентифицированному узлу, попадать в аргументы процесса, stdout, диагностику или ответы. Незавершённая аутентификация MUST ограничиваться по времени и объёму.

#### Scenario: Поддельный локальный endpoint
- **WHEN** адаптер подключается к узлу, не подтверждающему владение локальным ключом
- **THEN** адаптер отказывает в соединении до передачи MCP-запросов и не раскрывает ключ

#### Scenario: Неверное подтверждение или повтор старого обмена
- **WHEN** подключающийся процесс предъявляет неверное подтверждение, устаревший обмен или не завершает аутентификацию в срок
- **THEN** мост закрывает его соединение без доступа к документу и без изменения работающей сессии

### Requirement: Независимые MCP-сессии и один владелец документа

Мост MUST поддерживать отдельные MCP-сессии адаптеров. Инициализация и обнаружение инструментов MUST NOT занимать документ. Первый аутентифицированный клиент, вызвавший инструмент или чтение экспортного ресурса, MUST получать исключительное владение до закрытия соединения; обращения остальных MUST получать SESSION_BUSY без сведений документа и без вытеснения владельца.

#### Scenario: Второй клиент при работающем первом
- **WHEN** владелец работает с Figma, а второй клиент инициализируется и запрашивает список инструментов
- **THEN** инициализация и обнаружение доступны, а вызов инструмента вторым клиентом возвращает SESSION_BUSY; владелец продолжает работу

#### Scenario: Экспорт владельца недоступен другому клиенту
- **WHEN** другой клиент пытается прочитать известный URI экспортного ресурса владельца
- **THEN** запрос отклоняется с SESSION_BUSY без возврата содержимого

### Requirement: Безопасная передача управления

После закрытия или аварии адаптера владельца мост MUST аннулировать прежнюю привязку к плагину до допуска нового владельца. Очередь и разрешение записи MUST NOT переходить новому клиенту, старые scope MUST отклоняться. Неподтверждённые операции MUST NOT объявляться успешными или автоматически повторяться.

#### Scenario: Обычное закрытие владельца
- **WHEN** владелец закрывает MCP-соединение
- **THEN** общий процесс сохраняется, прежняя связь плагина сбрасывается, а другой подключённый клиент может получить управление после сброса и заново прочитать контекст

#### Scenario: Авария адаптера во время записи
- **WHEN** процесс владельца принудительно завершается при незавершённой операции
- **THEN** новый клиент не получает прежнюю очередь и разрешение записи; уже применённое не откатывается, неизвестный результат не повторяется

#### Scenario: Старый scope после передачи
- **WHEN** новый владелец предъявляет scope прежней привязки после восстановления связи плагина
- **THEN** команда отклоняется с SESSION_EXPIRED, а новый контекст сообщает актуальное поколение и выключенную запись

### Requirement: Жизненный цикл общего процесса

Общий мост MUST продолжать работу после закрытия всех адаптеров. Явная локальная команда `node dist/server/index.js --stop-bridge` MUST аутентифицированно останавливать мост и освобождать его ресурсы. Потеря моста MUST завершать соединения адаптеров без автоматического повторения запросов; последующий новый запуск MUST восстанавливать мост с сохранённым ключом.

#### Scenario: Нет подключённых клиентов
- **WHEN** все адаптеры завершены и затем запускается новый
- **THEN** новый адаптер использует тот же общий процесс без смены сохранённого ключа

#### Scenario: Явная остановка
- **WHEN** пользователь выполняет команду остановки
- **THEN** мост закрывает подключения, очищает сессионные ресурсы и освобождает порт; команда при уже остановленном мосте безопасно сообщает об отсутствии процесса

#### Scenario: Авария и последующий запуск
- **WHEN** общий мост аварийно завершается, после чего пользователь запускает новый адаптер
- **THEN** прежние соединения завершаются с диагностикой, новый мост использует сохранённый ключ, а прежние операции автоматически не воспроизводятся

### Requirement: Совместимость и диагностика версии

Общий мост MUST сохранять существующие инструменты, схемы, loopback-порт и протокол плагина. Несовместимая версия локального канала MUST отклоняться с диагностикой необходимости перезапуска. `FIGMA_MCP_PORT=0` MUST сохранять изолированный процессный режим для тестов без запуска общего фонового процесса.

#### Scenario: Несовместимая версия
- **WHEN** адаптер обнаруживает общий мост с неподдерживаемой версией локального протокола
- **THEN** он сообщает о необходимости явного перезапуска без вытеснения клиентов и без отправки команд документа

#### Scenario: Изолированные тесты
- **WHEN** существующий тест запускает сервер с FIGMA_MCP_PORT=0
- **THEN** сервер выбирает свободный порт, выводит прежние строки диагностики и освобождает ресурсы при закрытии клиента без общего daemon
