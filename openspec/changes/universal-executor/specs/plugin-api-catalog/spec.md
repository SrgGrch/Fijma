# Каталог Plugin API

## Purpose

Давать агенту компактную адресную справку для написания скриптов, различая декларации API, ограничения редактора и подтверждённые возможности подключённой среды.

## ADDED Requirements

### Requirement: Адресный справочник
Система MUST предоставлять индекс и адресуемые ресурсы сигнатур Plugin API, ограничения и примеры. Полный справочник MUST NOT включаться в tools/list или каждый ответ контекста. Индекс MUST быть доступен без подключённого документа.

#### Scenario: Запрос конкретного типа
- **WHEN** агент запрашивает ресурс InstanceNode
- **THEN** получает сигнатуры и ссылки на связанные типы с ограниченным размером ответа

### Requirement: Происхождение и поддержка
Каталог MUST указывать закреплённую версию типизаций и сборки. Контекст MUST отдельно сообщать editorType, documentAccess, capabilities и ограничения исполнения. Наличие декларации MUST NOT означать runtime-поддержку; неизвестная поддержка MUST обозначаться unknown, а не supported.

#### Scenario: Метод только в типизациях
- **WHEN** декларация существует, но проверка среды не подтверждает метод
- **THEN** каталог не обещает его доступность и сообщает соответствующее ограничение или unknown

### Requirement: Примеры со специальными правилами API
Каталог MUST включать проверяемые примеры агрегации текста и преобразования экземпляров с overrides, layout и variable bindings. Примеры MUST учитывать dynamic-page, загрузку шрифтов, смешанное форматирование, доступные свойства и кооперативную отмену. Генерация справочника MUST NOT генерировать обработчики записи из типов.

#### Scenario: Статистика типографики
- **WHEN** пример выполняется на тексте со смешанным форматированием
- **THEN** комбинации считаются по фактическим сегментам с единицами lineHeight, а не по приведённому к строке figma.mixed

#### Scenario: Недоступное связывание
- **WHEN** пример карточек встретил неподдерживаемое свойство или несовместимую переменную
- **THEN** сообщает пропуск или ошибку с причиной, не обещая произвольных изменений структуры экземпляра
