# Проверка задачи 1.5

Сборка из корня: `npx esbuild experiments/resources-probe/main.ts --bundle --target=es2017 --outfile=experiments/resources-probe/main.js`.
Автоматическая проверка: `node tests/resources-probe.mjs`.

В Figma Desktop откройте отдельный тестовый файл и импортируйте development-плагин через `experiments/resources-probe/manifest.json`. Запустите «Проверить», скопируйте весь отчёт из текстового поля. Вместе с отчётом запишите версию Desktop, ОС и тариф/лицензию файла.

Проверяются компонент/экземпляр, создание и чтение paint/text/effect/grid стилей, коллекция, FLOAT-переменная, alias, bind/unbind ширины и второй режим. Отказ добавления режима записывается отдельно и не прерывает чтение коллекции. Это проверка доступности API, а не реализация CRUD дизайн-системы или измерение максимального числа режимов.

В конце удаляются только объекты, созданные текущим запуском, в обратном порядке; ошибки очистки включены в отчёт. При закрытии плагина во время выполнения объекты могут остаться: используйте одноразовый файл. Тесты с подставным API не подтверждают ограничения реального Desktop. Задача 1.5 остаётся открытой до получения фактического отчёта.
