# Диагностика сессии Figma Desktop

Стенд не является сервером MCP или защищённым мостом. Запускайте его только в отдельных тестовых документах: контрольная кнопка создаёт прямоугольник. Остановите сервер после опыта.

1. Из корня проекта запустите `node experiments/session-probe/server.mjs`. Сервер слушает только `127.0.0.1:55263`.
2. Импортируйте `experiments/session-probe/manifest.json` в Figma Desktop и запустите «Figma MCP Bridge — диагностика сессии» в тестовом документе A. Дождитесь ответа и скопируйте идентификатор сессии A.
3. Закройте плагин, откройте отдельный тестовый документ B и запустите его снова. Убедитесь, что идентификатор изменился.
4. Введите идентификатор A в поле предыдущей сессии и нажмите «Проверить старую сессию». Ожидается `SESSION_EXPIRED`, новый прямоугольник появиться не должен.
5. Нажмите «Создать контрольный прямоугольник». Ожидается `CREATED` и узел `MCP session test marker` в документе B. Это подтверждает, что проверка действительно способна обнаружить запись.
6. Закройте плагин и остановите сервер Ctrl+C.

Проверка сессии здесь относится только к экспериментальному обработчику. Она не доказывает безопасность будущего рабочего моста; его маршрутизация и проверки должны быть реализованы и испытаны отдельно. Локальный тест обработчика: `node tests/session-probe.mjs`. После изменения main: `npx esbuild experiments/session-probe/main.ts --bundle --target=es2017 --outfile=experiments/session-probe/main.js`.
