# Единый диагностический плагин

Импортировать: `G:\Projects\AI\Figma-plugin-mcp\experiments\diagnostics\manifest.json`.

Сборка: `npm run build:diagnostics`. В тестовом файле нажмите «Запустить все проверки». За один запуск собираются локальные ресурсы, чтение/PNG и ещё один замер с автоматическим Stop через 500 мс после начала. Скопируйте общий отчёт. Существующие отдельные стенды сохранены для воспроизведения прежних результатов; новые проверки добавляются сюда.

Stop не прерывает синхронный API или экспорт, а останавливает последующие участки работы. Автоматический замер Stop проверяет создание фикстуры; он не подтверждает задержку остановки внутри экспорта. Закрытие плагина может оставить созданные объекты. Ошибки и очистка включены в отчёт. Лимиты предварительные.

В `read` дополнительно измеряются `yieldMs` (ожидание между порциями), `yields` (число ожиданий), `workMs` (остальное время). Новая сборка использует `scheduler: ui-message`: main отправляет yield с ID, UI возвращает его, main продолжает только после совпадающего ID. Внутри создания фикстуры и чтения таймеры больше не используются. Задержки доставки UI-сообщений всё ещё возможны; производительность новой сборки требует Desktop-проверки. Старые отчёты без scheduler относятся к таймерному варианту.

`boundaries` проверяет лимит одного узла, глубину 0, точный байтовый предел первой строки и предел на байт меньше на той же фикстуре без повторного создания фигур.
